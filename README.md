# SHROME

A fictional independent clothing brand website built using React.js and pure CSS.

## Features

* Responsive fashion website
* Product filtering
* Product quick view
* Shopping bag counter
* Interactive navigation
* Responsive design

## Technologies

* React.js
* JavaScript
* JSX
* Pure CSS

## React Concepts

* Components
* Props
* useState
* Event handling
* Conditional rendering
* Array rendering with map()

## Installation

```bash
npm install
npm run dev
```

## Purpose

This project was created as a React.js school activity.
